Robo-guide API v1

Локальный API: http://127.0.0.1:8089/api/v1.

  • OpenAPI 3.1: HTTP-контракт
  • JSON Schema событий WebSocket
  • Примеры событий
  • Сессии, операции, ошибки и миграция

POST /auth/challenge → POST /auth/verify (nonce, backend=pin, pin). Сессия хранится в HttpOnly cookie. Для POST /missions и /speech обязателен Idempotency-Key. Ответ 202 означает принятие запроса; результат читается через /operations/{id} или WebSocket /events.

Каждое подключение WebSocket начинается со snapshot. State и heartbeat содержат полный снимок, включая feedback/result операций. При смене instance_id старые идентификаторы недействительны. Статус unknown означает неопределённый исход, а не успешное завершение.
